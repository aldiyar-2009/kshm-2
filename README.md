# КШМ-2 — интерактивная 3D-презентация

3D-модель командно-штабной машины **КШМ-2 на шасси КАМАЗ 43118-23027-50**. Сайт сделан на чистых HTML, CSS и JavaScript, а 3D отрисовывается библиотекой [three.js](https://threejs.org), которая подключается с CDN. Сборка и установка зависимостей не нужны.

## Возможности

Режимы просмотра (вкладки сверху):

- **Продукт** — машина целиком, метки с описанием узлов.
- **Рентген** — обшивка кабины и фургона становится прозрачной, видны силовой каркас фургона, рама, отсеки и оборудование.
- **Разрез** — крыша и правый борт становятся прозрачными, видна планировка. Клик по отсеку переносит внутрь.
- **Разобранный** — машина разлетается на сотни деталей с подписями узлов; степень разлёта регулируется ползунком.
- **Раскладка** — все узлы разложены на площадке рядами, как на сборочном участке.

Дополнительно:

- **Узел** (нижняя панель) — выделить кабину, шасси, фургон, мачты с антенной или интерьер; остальное становится полупрозрачным.
- **Слои** — включить или выключить обшивку, каркас, интерьер, оборудование и шасси.
- **Тема** — площадка под пасмурным вечерним небом (по умолчанию) или светлая студия. На площадке — вид как в сцене Blender: мокрый асфальт с лужами и отражением машины, склады и фонари на горизонте, дымка, мокрый лак с дорожной грязью снизу, включённые фары, габариты и проблесковый маячок.
- **Экскурсия** — автоматический обзор: шасси, кабина, бак, ДГУ, фургон, антенна, мачты, входы, рентген, разбор, раскладка, планировка и все 4 отсека изнутри.
- **Вид изнутри** — обзор отсека на 360° (тянуть мышью или пальцем, колесо меняет угол обзора).
- **Развернуть** — мачты выдвигаются на 10 м, поднимается спутниковая антенна и мачта видеонаблюдения, открываются двери, опускаются лестница и трап, поднимается сиденье дивана с баком для воды, раскладывается край стола.
- **Метки** и **клик по любой детали** — открывают её описание.
- Цифровые часы в командно-штабном отсеке показывают текущее время Астаны, Москвы и UTC.
- Вёрстка адаптирована под телефоны.

## Структура

```
index.html      — страница и интерфейс
css/style.css   — стили
js/main.js      — сцена, камера, режимы, экскурсия, интерфейс
js/kshm.js      — процедурная 3D-модель машины и отсеков
js/data.js      — тексты и характеристики (легко редактировать)
js/yard.js      — площадка: небо, мокрый асфальт с отражением, склады, фонари
assets/env.hdr  — карта уличного освещения для студии (Poly Haven, «Pedestrian Overpass», CC0)
assets/sky.jpg, assets/sky_env.hdr — небо площадки и его карта освещения (Poly Haven, «Kloofendal Overcast», CC0)
```

Небо берётся из той же HDRI, что освещает сцену в Blender. Чтобы пересобрать его (другая HDRI, яркость, оттенок): `blender --background --python blender/export_web_sky.py`.

Реалистичный рендер: физические материалы (лак с прозрачным верхним слоем, тонированное стекло, резина), HDR-освещение, мягкие тени. На компьютерах дополнительно включается затенение стыков (GTAO); на телефонах оно отключено ради скорости.

Скорость: пока машина собрана и неподвижна, её 942 детали рисуются склеенными по материалам, тени пересчитываются только при движении, а качество (разрешение, затенение стыков, ореол, отражение в асфальте) автоматически снижается, если кадров меньше ~33 в секунду.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы из этой папки.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Локальный запуск

Модули ES не загружаются, если открыть файл двойным щелчком (`file://`), поэтому нужен любой локальный сервер:

```bash
npx http-server -p 8080
```

После этого откройте http://localhost:8080.

```html
<iframe src="https://<логин>.github.io/<репозиторий>/" style="width:100%;height:80vh;border:0" allowfullscreen></iframe>
```
