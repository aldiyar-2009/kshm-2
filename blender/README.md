# КШМ-2 в Blender — фотореалистичная сцена для видео

## Файлы

| Файл | Что это |
|---|---|
| `kshm2_scene.blend` | Готовая сцена: модель, материалы, небо, площадка, 5 камер с анимацией |
| `render.bat` | Двойной клик — финальный рендер ролика 1080×1920 (Reels/Shorts) |
| `build_scene.py` | Пересобирает сцену с нуля из `kshm2.glb` (если поменяли модель на сайте) |
| `render_video.py` | Рендер кадров на видеокарте + сборка MP4 |
| `render_tests.py` | Быстрые тестовые кадры с каждой камеры |
| `kshm2.glb`, `kshm2_deployed.glb`, `kshm2_exploded.glb` | Модель из веб-версии: транспортное положение, мачты 10 м, разобранный вид |
| `environment.py` | Городское окружение (процедурное) |
| `sky_overcast_4k.hdr` | Пасмурное небо — HDRI Poly Haven, CC0 (запасной вариант: `sky_partly_cloudy_4k.hdr`) |

## Что в сцене

- **Свет:** настоящее небо с облаками (HDRI 4K) + солнце, совпадающее с солнцем на панораме; мягкие тени.
- **Площадка:** асфальт с крошкой и лужами — в них отражается машина; разметка парковки.
- **Материалы:** лак с прозрачным верхним слоем и «апельсиновой коркой», настоящее стекло (преломление — виден салон), резина с микрорельефом, металл, лёгкая дорожная грязь снизу.
- **Фаски** на всех рёбрах — ловят блики, как на реальных деталях.
- **Свет внутри:** панели в каждом отсеке, светодиодные линии, включённые фары и маячок.

## Ролик (23 с, 30 к/с, 700 кадров)

| Кадры | Камера | Что происходит |
|---|---|---|
| 1–150 | CAM_1_Въезд | Машина въезжает во двор между домами и тормозит, колёса крутятся |
| 151–240 | CAM_2_Облёт | Облёт спереди-справа к борту |
| 241–300 | CAM_3_Колёса | Низкий проезд камеры вдоль колёс |
| 301–470 | CAM_4_Разборка | Как в видео с самолётом: кузов разлетается на детали, видно каркас и отсеки, затем собирается |
| 471–560 | CAM_5_Отсек | Панорама внутри операторского отсека |
| 561–700 | CAM_6_Развёртывание | Мачты поднимаются на 10 м, антенна и двери раскрываются |

Окружение (коллекция «Окружение_город»): кирпичные многоэтажки с окнами (часть горит), синие модульные здания,
фонари, столб с купольной камерой, бордюры, тротуар; небо — пасмурная HDRI «Kloofendal Overcast (Pure Sky)», Poly Haven, CC0.
Движение машины — объект «KSHM2_Движение»; чтобы изменить путь, двигайте его ключи (колёса пересчитываются скриптом build_scene.py).

## Рендер

- **Финал:** запустите `render.bat`. Около 30–35 с на кадр на RTX 4050 → ~6–7 часов.
  Окно можно закрыть и запустить снова — готовые кадры не пересчитываются.
  Результат: `renders/KSHM2_reels.mp4` и кадры PNG в `renders/frames/`.
- **Быстрее:** в `.bat` добавьте после `render_video.py` аргументы `-- 96` (меньше сэмплов, шумоподавление останется).
- **Черновик:** `blender --background blender\kshm2_scene.blend --python blender\render_video.py -- 16 50 preview`.

## Советы для максимальной реалистичности

- Добавьте в монтаже лёгкое дрожание камеры, звук двигателя и ветра — мозг перестаёт искать «3D».
- Цветокоррекция в CapCut/DaVinci: чуть зерна плёнки и виньетка.
- Сцену «закат»: в мире сцены поверните `Mapping → Rotation Z`, у солнца — тот же угол, и уменьшите `Солнце → Strength`.
